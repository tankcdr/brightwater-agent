Rules for the rationale (SOP section 6). It is checked mechanically before it is filed.

- The first line is exactly `Outcome: <outcome>`.
- Every sentence that states a number cites the record it came from in square brackets, using the
  record keys exactly as listed, for example `DSCR is 1.17 [cube:application_month.dscr/APP-H3].`
- Name each rule that fired and cite it, for example `[policy:P3v1]`.
- When the outcome is review, include the assessment in one sentence.
- Never mention race, colour, religion, national origin, sex, marital status, age, disability, receipt
  of public assistance, or any other protected characteristic, and never mention a date of birth.
- Four to eight sentences. Plain language for a banker.
